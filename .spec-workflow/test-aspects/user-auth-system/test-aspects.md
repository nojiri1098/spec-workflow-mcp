# ユーザー認証システム - テスト観点

## TEP-001: ユーザー登録機能のテスト観点

### 正常系テスト観点

#### 基本的な登録フロー
- **TEP-001-01**: 有効な情報での新規ユーザー登録
  - 前提条件: 未登録のメールアドレスを使用
  - 入力: 有効なメール、強いパスワード、氏名
  - 期待結果: 登録成功、確認メール送信

- **TEP-001-02**: メール認証完了による有効化
  - 前提条件: 登録済み、未認証状態
  - 操作: 確認メール内のリンクをクリック
  - 期待結果: アカウント有効化、ログイン可能

#### 任意項目の動作
- **TEP-001-03**: 電話番号未入力での登録
  - 入力: 電話番号フィールドを空欄
  - 期待結果: 登録成功

### 異常系テスト観点

#### バリデーションエラー
- **TEP-001-04**: 無効なメールアドレス形式
  - 入力: "invalid-email"
  - 期待結果: エラーメッセージ表示、登録失敗

- **TEP-001-05**: 弱いパスワード
  - 入力: "123456"（8文字未満、記号なし）
  - 期待結果: パスワード強度エラー

- **TEP-001-06**: 重複メールアドレス
  - 前提条件: 既に登録済みのメールアドレス
  - 期待結果: 重複エラー表示

#### 境界値テスト
- **TEP-001-07**: パスワード最小長（8文字）
  - 入力: "Pass123!"（8文字ちょうど）
  - 期待結果: 登録成功

- **TEP-001-08**: パスワード最大長
  - 入力: 128文字のパスワード
  - 期待結果: 登録成功または適切な制限

  - 前提条件: 有効化済みアカウント

#### 認証失敗
- **TEP-002-04**: 間違ったパスワード
  - 入力: 正しいメール、間違ったパスワード
  - 期待結果: ログイン失敗、エラーメッセージ

- **TEP-002-05**: 存在しないメールアドレス
  - 入力: 未登録のメールアドレス
  - 期待結果: ログイン失敗

#### セキュリティ制御
- **TEP-002-06**: ログイン試行回数制限
  - 操作: 5回連続ログイン失敗
  - 期待結果: アカウントロック（30分）

- **TEP-002-07**: 未認証アカウントでのログイン
  - 前提条件: メール認証未完了
  - 期待結果: ログイン失敗、認証要求メッセージ

## TEP-004: セキュリティテスト観点

### CSRF攻撃対策
- **TEP-004-01**: CSRFトークン未送信
  - 操作: CSRFトークンなしでAPI呼び出し
  - 期待結果: 403 Forbidden

- **TEP-004-02**: 無効なCSRFトークン
  - 操作: 偽のCSRFトークンでAPI呼び出し
  - 期待結果: 403 Forbidden

### セッションセキュリティ
- **TEP-004-03**: セッションハイジャック対策
  - 操作: 他のセッションIDで認証試行
  - 期待結果: 認証失敗

- **TEP-004-04**: セッション固定攻撃対策
  - 操作: ログイン前後でセッションID確認
  - 期待結果: セッションID変更

### 入力値検証
- **TEP-004-05**: XSS攻撃対策
  - 入力: `<script>alert('xss')</script>`
  - 期待結果: スクリプトエスケープまたは除去

- **TEP-004-06**: SQLインジェクション対策
  - 入力: `'; DROP TABLE users; --`
  - 期待結果: エスケープ処理、攻撃失敗
